## Mit csinál

A GTweak átfogó eszközkészletet kínál, amely teljes irányítást biztosít a Windows operációs rendszer felett. Ahelyett, hogy több rendszermenüben navigálna, egyetlen felületről biztonságosan letilthatja a felesleges háttérszolgáltatásokat, eltávolíthatja a beépített kéretlen programokat, és speciális rendszerkonfigurációkat alkalmazhat.

| Funkció | Részletek |
|---|---|
| **Rendszer aktiválása** | A Windows aktiválása HWID és KMS módszerekkel |
| **Biztonsági ellenőrzés** | A Windows Defender, a SmartScreen, a kártevőirtó, a VBS és az UAC letiltása |
| **Frissítések kezelése** | A Windows-frissítések letiltása és szüneteltetése; az ideiglenes frissítési fájlok eltávolítása |
| **Rendszeroptimalizálás** | A nem használt szolgáltatások, szükségtelen hálózati protokollok (Teredo, ISATAP, IPv6), beépített diagnosztikai eszközök és a töredezettségmentesítés letiltása |
| **Adatvédelem és telemetria** | A billentyűnaplók és a telemetria letiltása (Windows, NVIDIA, Intel). Adatgyűjtő szolgáltatások, Feladatütemező feladatok, személyre szabott hirdetések, rendszerszalaghirdetések (SCOOBE), értesítések és tippek letiltása. A Microsoft árnyéktartományainak blokkolása a hosts fájl és a tűzfal segítségével |
| **Bloatware eltávolítás és tisztítás** | A OneDrive és a Microsoft Edge eltávolítása az összes kapcsolódó adattal és a WebView2-vel. Előre telepített szabványos UWP alkalmazások és AI-asszisztensek (Cortana, Copilot, Recall) eltávolítása |
| **Felület testreszabása** | Témák, ablakbeállítások, tálca elrendezés és ikonok módosítása. Személyre szabott hirdetések, szalaghirdetések és tippek letiltása |
| **Hardver és perifériák** | A billentyűzet és az egér beállításainak konfigurálása: billentyűszűrés, ragadós billentyűk és mutatógyorsítás letiltása. A maximális teljesítményű energiagazdálkodási terv alkalmazása. A Realtek High Definition Audio hangkésleltetés javítása az energiagazdálkodási beállításokon keresztül |
| **Lemez és karbantartás** | RAM, ideiglenes fájlok, ikon-gyorsítótárak törlése és a `Windows.old` mappa biztonságos eltávolítása. Adattömörítés és kicsomagolás NTFS segítségével a helytakarékosság érdekében |
| **Speciális vezérlés** | A hardverkonfiguráció és a rendszer összetevőinek megtekintése. Egyéni parancsfájlok (`.ps1`, `.cmd`, `.bat`, `.reg`) futtatása TrustedInstaller jogosultságokkal |

## Rendszerkövetelmények

> ⚠️ A segédprogramot kizárólag megbízható forrásból letöltött hivatalos Windows-képekhez tervezték. Ha a Windows csökkentett/módosított verzióját telepítette, kizárólag Ön felelős annak működéséért.

```c++
Windows támogatás: 10-től (build 18362.116)
Telepített platform: .NET Framework 4.8
```

> Futtassa az alkalmazást Rendszergazdaként.
> 
> A szoftver használata előtt tiltsa le a víruskeresőt, vagy adja hozzá a GTweak-et a Windows Defender kivételeihez.

<details>
<summary><b>Hogyan fordítsd le a GTweak-et</b></summary>
 
**I. Pull Request küldése**
- Készíts egy fork-ot a tárolóból [itt](https://github.com/Greedeks/GTweak/fork).
- Töltsd le az [angol alapfájlt (Localize.xaml)](https://github.com/Greedeks/GTweak/blob/main/.Source/GTweak/Languages/en/Localize.xaml) **vagy** böngészd és másold le a [meglévő fordítások](https://github.com/Greedeks/GTweak/tree/main/.Source/GTweak/Languages) egyikét más nyelveken.
- Fordítsd le a fájlt, és mentsd el a [nyelvkódodnak](https://learn.microsoft.com/en-us/windows-hardware/manufacture/desktop/available-language-packs-for-windows?view=windows-11) megfelelő nevű mappába (pl. `ko` koreai, `fr` francia).
</br>Regionális változatok esetén: nyelv-régió (pl. `pt-br` brazíliai portugál, `zh-cn` egyszerűsített kínai).
- Helyezd a mappát ide:
<div>
    <pre>
📂 .Source
└── 📁 GTweak
    └── 📁 Languages
        ├── 📁 en
        ├── 📁 ru
        └── 📁 [a-te-nyelvkódod]
    </pre>
</div>

- Add hozzá a nyelved nevét (ahogy az anyanyelveden írják) a [LanguageCatalog](https://github.com/Greedeks/GTweak/blob/main/.Source/GTweak/Languages/LanguageCatalog.xaml) fájlhoz.  
  ⚠️ Ügyelj arra, hogy kövesd a fájlban található [MEGJEGYZÉST](https://github.com/Greedeks/GTweak/blob/main/.Source/GTweak/Languages/LanguageCatalog.xaml#L5-L11).
- Küldj egy **Pull Request**-et a módosításaiddal. </br></br>

**II. Kérés Issue-n keresztül**
- Ha nem vagy ismerős a Git használatában, nyiss egy [Feature Request issue](https://github.com/Greedeks/GTweak/issues/new?template=%E2%9C%A8-feature-request-.yaml&title=[Feature]%20Add%20translation)-t.
  - Add meg a cél [nyelvkódot](https://learn.microsoft.com/en-us/windows-hardware/manufacture/desktop/available-language-packs-for-windows?view=windows-11).
  - Add meg a nyelved nevét az anyanyelveden írva, a [MEGJEGYZÉS](https://github.com/Greedeks/GTweak/blob/main/.Source/GTweak/Languages/LanguageCatalog.xaml#L5-L11) szerint.
  - Csatold a lefordított `Localize.xaml` fájlodat.
</br>

</details>

> [!NOTE]  
> A jelenlegi fordítás hiányos lehet, mivel előfordulhat, hogy olyan új funkciók kerültek beépítésre, amelyek még nem lettek lefordítva. Ilyen esetekben a program ezen részei alapértelmezés szerint angolul jelennek meg.
