## Kaj program počne

GTweak ponuja celovit nabor orodij, s katerimi dobite popoln nadzor nad operacijskim sistemom Windows. Namesto krmarjenja po številnih sistemskih menijih lahko iz enega samega vmesnika varno onemogočite nepotrebne storitve v ozadju, odstranite vgrajeno nesnago (bloatware) in uporabite napredne konfiguracije sistema.

| Funkcija | Podrobnosti |
|---|---|
| **Aktivacija sistema** | Aktiviranje sistema Windows z metodami HWID in KMS |
| **Nadzor varnosti** | Onemogočanje programov Windows Defender, SmartScreen, Antimalware, VBS in UAC |
| **Upravljanje posodobitev** | Onemogočanje in začasna ustavitev posodobitev sistema Windows; odstranjevanje začasnih datotek s posodobitvami |
| **Optimizacija sistema** | Onemogočanje neuporabljenih sistemskih storitev, nepotrebnih omrežnih protokolov (Teredo, ISATAP, IPv6), vgrajenih diagnostičnih orodij in defragmentacije diska |
| **Zasebnost in telemetrija** | Onemogočanje keyloggerjev in telemetrije za Windows, NVIDIA in Intel. Onemogočanje storitev zbiranja podatkov, opravil v razporejevalniku, prilagojenih oglasov, sistemskih pasic, SCOOBE, obvestil in nasvetov. Blokiranje Microsoftovih senčnih domen prek gostiteljev in požarnega zidu |
| **Čiščenje in navlaka** | Odstranjevanje programov OneDrive in Microsoft Edge skupaj z brisanjem vseh povezanih podatkov in WebView2. Odstranjevanje standardnih prednameščenih aplikacij UWP in pomočnikov umetne inteligence: Cortana, Copilot in Recall |
| **Prilagoditev vmesnika** | Prilagajanje tem, nastavitev oken, postavitve opravilne vrstice in ikon. Onemogočanje prilagojenih oglasov, pasic in nasvetov |
| **Strojna oprema** | Konfiguriranje tipkovnice in miške: onemogočanje filtriranja tipk, lepljivih tipk in pospeševanja kazalca. Uporaba načrta porabe energije za najvišjo zmogljivost. Prilagajanje nastavitev porabe energije za gonilnike Realtek High Definition Audio za odpravo zakasnitve zvoka |
| **Disk in vzdrževanje** | Brisanje RAM-a, začasnih datotek, predpomnilnikov ikon in varno brisanje mape `Windows.old`. Stiskanje in razširjanje datotek z uporabo NTFS za prihranek prostora |
| **Napreden nadzor** | Ogled konfiguracije strojne opreme in spremljanje sistemskih komponent. Izvajanje skriptov po meri (`.ps1`, `.cmd`, `.bat`, `.reg`) s privilegiji TrustedInstaller |

## Sistemske zahteve

> ⚠️ Pripomoček je zasnovan izključno za uradne slike sistema Windows, prenesene iz zaupanja vrednih virov. Če ste namestili obrezano/spremenjeno različico sistema Windows, ste izključno sami odgovorni za njegovo delovanje.

```c++
Podpora za Windows: od različice 10 (graditev 18362.116)
Nameščena platforma: .NET Framework 4.8
```

> [!WARNING]
> Zaženite aplikacijo kot skrbnik.
> 
> Pred uporabo programske opreme onemogočite protivirusni program ali dodajte GTweak med izključitve programa Windows Defender.

<summary><b>Kako prevesti GTweak</b></summary>
 
**I. Oddajte zahtevo za združitev sprememb (Pull Request)**
- Ustvarite razvejitev repozitorija [tukaj](https://github.com/Greedeks/GTweak/fork).
- Prenesite [osnovno datoteko za angleščino (Localize.xaml)](https://github.com/Greedeks/GTweak/blob/main/.Source/GTweak/Languages/en/Localize.xaml) **ali** prebrskajte in kopirajte iz [obstoječih prevodov](https://github.com/Greedeks/GTweak/tree/main/.Source/GTweak/Languages) v drugih jezikih.
- Prevedite datoteko in jo shranite v mapo, poimenovano po vaši [kodi jezika](https://learn.microsoft.com/en-us/windows-hardware/manufacture/desktop/available-language-packs-for-windows?view=windows-11) (npr. `ko` za korejščino, `sl-si` za slovenščino).
</br>Za regionalne različice: jezikovna_regija (npr. `pt-br` za brazilsko portugalščino, `zh-cn` za poenostavljeno kitajščino).
- Ustvarite mapo v:
<div>
    <pre>
📂 .Source
└── 📁 GTweak
    └── 📁 Languages
        ├── 📁 en
        ├── 📁 ru
        └── 📁 [vaša-koda-jezika]
    </pre>
</div>

- Dodajte ime svojega jezika (kot je zapisano v vašem maternem jeziku) v [LanguageCatalog](https://github.com/Greedeks/GTweak/blob/main/.Source/GTweak/Languages/LanguageCatalog.xaml).  
  ⚠️ Upoštevajte [OPOMBO](https://github.com/Greedeks/GTweak/blob/main/.Source/GTweak/Languages/LanguageCatalog.xaml#L5-L11) v datoteki.
- Oddajte **zahtevo za združitev sprememb (Pull Request)** s svojimi spremembami. </br></br>

**II. Zahteva preko težav (Issue)**
- Če niste seznanjeni z Gitom, odprite [zahtevo za funkcijo (Feature Request)](https://github.com/Greedeks/GTweak/issues/new?template=%E2%9C%A8-feature-request-.yaml&title=[Feature]%20Add%20translation).
  - Navedite ciljno [kodo jezika](https://learn.microsoft.com/en-us/windows-hardware/manufacture/desktop/available-language-packs-for-windows?view=windows-11).
  - Navedite ime svojega jezika, zapisano v vašem maternem jeziku, v skladu z [OPOMBO](https://github.com/Greedeks/GTweak/blob/main/.Source/GTweak/Languages/LanguageCatalog.xaml#L5-L11).
  - Priložite prevedeno datoteko `Localize.xaml`.
</br>
