## Що він робить

GTweak надає комплексний набір інструментів, щоб дати вам повний контроль над операційною системою Windows. Замість того, щоб переміщатися через численні системні меню, ви можете безпечно вимикати непотрібні фонові служби, видаляти вбудоване сміття (bloatware) та застосовувати розширені налаштування системи з єдиного інтерфейсу.

| Функція | Деталі |
|---|---|
| **Активація системи** | Активація Windows із використанням методів HWID та KMS |
| **Контроль безпеки** | Вимкнення Windows Defender, SmartScreen, Antimalware, VBS та UAC |
| **Керування оновленнями** | Вимкнення та призупинення оновлень Windows; видалення тимчасових файлів оновлень |
| **Оптимізація системи** | Вимкнення невикористовуваних та непотрібних служб, непотрібних мережевих протоколів (Teredo, ISATAP, IPv6), вбудованих діагностичних інструментів Windows та дефрагментації |
| **Конфіденційність і телеметрія** | Вимкнення кейлогерів та телеметрії Windows, NVIDIA та Intel. Вимкнення служб та подій, пов'язаних зі збором даних користувачів, завдань у Планувальнику Windows, персоналізованої реклами, системних банерів (включаючи SCOOBE), сповіщень та пропозицій. Блокування тіньових доменів Microsoft збору даних через hosts та брандмауер |
| **Видалення сміття та очищення** | Видалення OneDrive та Microsoft Edge із очищенням усіх пов'язаних даних та WebView2. Видалення стандартних попередньо встановлених додатків (UWP) у Windows 10/11 та помічників із ШІ: Cortana, Copilot та Recall |
| **Кастомізація інтерфейсу** | Налаштування інтерфейсу: зміна тем, параметрів вікон, розкладки панелі завдань та піктограм. Вимкнення персоналізованої реклами, банерів та пропозицій |
| **Обладнання та периферія** | Налаштування параметрів клавіатури та миші: вимкнення фільтрації, залипання клавіш та акселерації курсора. Застосування схеми електропостачання «Максимальна продуктивність». Налаштування електропостачання драйверів Realtek High Definition Audio для виправлення затримки звуку |
| **Диск та обслуговування** | Очищення оперативної пам'яті, тимчасових файлів, кешу та безпечне видалення папки `Windows.old`. Стиснення та розпакування файлів за допомогою NTFS для економії місця |
| **Розширене керування** | Перегляд конфігурації та моніторинг компонентів системи. Виконання власних скриптів (`.ps1`, `.cmd`, `.bat`, `.reg`) з правами TrustedInstaller |

## Системні вимоги

> ⚠️ Утиліту призначено для використання лише з офіційними образами Windows, завантаженими з надійних джерел. Якщо встановлено обрізану/модифіковану версію Windows, за її працездатність відповідальність покладається на вас.

```c++
Підтримка Windows: починаючи з Windows 10 (build 18362.116)
Встановлена платформа: .NET Framework 4.8
```

> [!WARNING]
> Запустіть програму від імені Адміністратора.
> 
> Перед використанням зупиніть антивірус або додайте GTweak до винятків Windows Defender.

<details>
<summary><b>Як перекласти GTweak</b></summary>
 
**I. Надішліть Pull Request**
- Зробіть форк репозиторію [тут](https://github.com/Greedeks/GTweak/fork).
- Завантажте [базовий англійський файл (Localize.xaml)](https://github.com/Greedeks/GTweak/blob/main/.Source/GTweak/Languages/en/Localize.xaml) **або** перегляньте та скопіюйте з [існуючих перекладів](https://github.com/Greedeks/GTweak/tree/main/.Source/GTweak/Languages) іншими мовами.
- Перекладіть файл і збережіть його в папку з назвою вашого [коду мови](https://learn.microsoft.com/en-us/windows-hardware/manufacture/desktop/available-language-packs-for-windows?view=windows-11) (наприклад, `ko` для корейської, `uk` для української).
</br>Для регіональних варіантів: мова-регіон (наприклад, `pt-br` для бразильської португальської, `zh-cn` для спрощеної китайської).
- Розмістіть папку в:
<div>
    <pre>
📂 .Source
└── 📁 GTweak
    └── 📁 Languages
        ├── 📁 en
        ├── 📁 ru
        └── 📁 [ваш-код-мови]
    </pre>
</div>

- Додайте назву вашої мови (написану вашою рідною мовою) до [LanguageCatalog](https://github.com/Greedeks/GTweak/blob/main/.Source/GTweak/Languages/LanguageCatalog.xaml).  
  ⚠️ Обов'язково дотримуйтесь [ПРИМІТКИ](https://github.com/Greedeks/GTweak/blob/main/.Source/GTweak/Languages/LanguageCatalog.xaml#L5-L11) усередині файлу.
- Надішліть **Pull Request** з вашими змінами. </br></br>

**II. Запит через Issue**
- Якщо ви не знайомі з Git, відкрийте [Feature Request issue](https://github.com/Greedeks/GTweak/issues/new?template=%E2%9C%A8-feature-request-.yaml&title=[Feature]%20Add%20translation).
  - Вкажіть цільовий [код мови](https://learn.microsoft.com/en-us/windows-hardware/manufacture/desktop/available-language-packs-for-windows?view=windows-11).
  - Надайте назву вашої мови, написану вашою рідною мовою відповідно до [ПРИМІТКИ](https://github.com/Greedeks/GTweak/blob/main/.Source/GTweak/Languages/LanguageCatalog.xaml#L5-L11).
  - Прикріпіть ваш перекладений файл `Localize.xaml`.
</br>

</details>

> [!NOTE]  
> Поточний переклад може бути неповним, оскільки могли бути додані нові функції, які ще не перекладені. У таких випадках ці частини програми за замовчуванням відображатимуться англійською мовою.
