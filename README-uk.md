## ✦ Налаштування Всього

**Активація та Безпека**
- Активація Windows із використанням методів HWID та KMS
- Вимкнення Windows Defender, SmartScreen, Antimalware, VBS та UAC (контролю облікових записів)

**Оновлення та Служби**
- Вимкнення та призупинення оновлень Windows; видалення тимчасових файлів оновлень
- Вимкнення невикористовуваних та непотрібних системних служб

**Конфіденційність та Телеметрія**
- Вимкнення кейлогерів та телеметрії для Windows, NVIDIA та Intel
- Вимкнення служб, подій та завдань у Планувальнику завдань, пов'язаних зі збором даних користувачів
- Блокування тіньових доменів Microsoft, що збирають дані, через файл hosts та брандмауер

**Мережа та Діагностика**
- Вимкнення непотрібних мережевих протоколів: Teredo, ISATAP та IPv6
- Вимкнення вбудованих діагностичних інструментів Windows та дефрагментації дисків

**Зайве ПЗ та ШІ**
- Видалення OneDrive та Microsoft Edge із очищенням усіх пов'язаних даних та компонента WebView2
- Видалення стандартних попередньо встановлених додатків (UWP) у Windows 10/11
- Видалення та вимкнення помічників зі штучним інтелектом: Cortana, Copilot та Recall

**Інтерфейс та Сповіщення**
- Налаштування інтерфейсу: зміна тем, параметрів вікон, розташування панелі завдань та піктограм
- Вимкнення персоналізованої реклами, системних банерів, SCOOBE, сповіщень, рекомендацій та пропозицій

**Обладнання та Продуктивність**
- Налаштування параметрів клавіатури та миші: вимкнення фільтрації, залипання клавіш та акселерації курсора
- Налаштування параметрів Windows та застосування схеми електропостачання «Максимальна продуктивність»
- Налаштування електропостачання драйверів Realtek High Definition Audio для виправлення затримки звуку

**Обслуговування та Додатково**
- Очищення оперативної пам'яті, тимчасових файлів, кешу піктограм та безпечне видалення папки Windows.old
- Стиснення та відновлення файлів і тек з використанням NTFS для економії місця
- Перегляд конфігурації обладнання та моніторинг компонентів системи
- Виконання користувацьких скриптів (`.ps1`, `.cmd`, `.bat`, `.reg`) з правами TrustedInstaller
  
<br>

## ✦ Системні Вимоги
```c++
Підтримка Windows: починаючи з 10 (build 18362.116)
Встановлена платформа: .NET Framework 4.8
Запуск від імені адміністратора: обов'язково
Антивірус: додати у винятки або вимкнути
```

> ⚠️ Утиліту призначено для використання лише з офіційними образами Windows, завантаженими з надійних джерел. Якщо встановлено обрізану/модифіковану версію Windows, за її працездатність відповідальність покладається виключно на вас.

<details>
<summary><b>Як перекласти GTweak</b></summary>
 
**I. Надіслати Pull Request**
- Зробіть форк репозиторію [тут](https://github.com/Greedeks/GTweak/fork).
- Завантажте [базовий англійський файл (Localize.xaml)](https://github.com/Greedeks/GTweak/blob/main/.Source/GTweak/Languages/en/Localize.xaml) **або** знайдіть та скопіюйте з [наявних перекладів](https://github.com/Greedeks/GTweak/tree/main/.Source/GTweak/Languages) іншими мовами.
- Перекладіть файл та збережіть його в папці з назвою вашого [коду мови](https://learn.microsoft.com/en-us/windows-hardware/manufacture/desktop/available-language-packs-for-windows?view=windows-11) (наприклад, `ko` для корейської, `fr` для французької).
</br>Для регіональних варіантів: мова-регіон (наприклад, `pt-br` для бразильської португальської, `zh-cn` для спрощеної китайської).
- Розмістіть папку тут:
<div>
    <pre>
📂 .Source
└── 📁 GTweak
    └── 📁 Languages
        ├── 📁 en
        ├── 📁 ru
        └── 📁 [ваш-код-мови]
    </pre>
</div>

- Додайте назву вашої мови (як вона пишеться вашою рідною мовою) до [LanguageCatalog](https://github.com/Greedeks/GTweak/blob/main/.Source/GTweak/Languages/LanguageCatalog.xaml).  
  ⚠️ Обов'язково дотримуйтеся вказівок [NOTE](https://github.com/Greedeks/GTweak/blob/main/.Source/GTweak/Languages/LanguageCatalog.xaml#L5-L11) всередині файлу.
- Надішліть **Pull Request** із вашими змінами. </br></br>

**II. Запит через Issue**
- Якщо ви не знайомі з Git, відкрийте [Issue Feature Request](https://github.com/Greedeks/GTweak/issues/new?template=%E2%9C%A8-feature-request-.yaml&title=[Feature]%20Add%20translation).
  - Вкажіть цільовий [код мови](https://learn.microsoft.com/en-us/windows-hardware/manufacture/desktop/available-language-packs-for-windows?view=windows-11).
  - Вкажіть назву вашої мови, написану рідною мовою, відповідно до [NOTE](https://github.com/Greedeks/GTweak/blob/main/.Source/GTweak/Languages/LanguageCatalog.xaml#L5-L11).
  - Прикріпіть ваш перекладений файл `Localize.xaml`.
</br>

</details>

> [!NOTE]  
> Поточний переклад може бути неповним, оскільки могли бути додані нові функції, які ще не перекладені. У таких випадках ці частини програми за замовчуванням відображатимуться англійською мовою.
