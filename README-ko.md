## ✦ 모든 기능 사용자 지정

**정품 인증 및 보안**
- HWID 및 KMS 방식을 통한 Windows 정품 인증
- Windows Defender, SmartScreen, Antimalware, VBS 및 UAC 비활성화

**업데이트 및 서비스**
- Windows 업데이트 비활성화 및 일시 중지, 임시 업데이트 파일 삭제
- 사용하지 않는 불필요한 시스템 서비스 비활성화

**개인 정보 보호 및 원격 분석**
- Windows, NVIDIA 및 Intel의 키로거 및 원격 분석 비활성화
- 사용자 데이터 수집과 관련된 서비스, 이벤트 및 작업 스케줄러 작업 비활성화
- 호스트 파일 및 방화벽을 통한 Microsoft 섀도우 도메인 차단

**네트워크 및 진단**
- 불필요한 네트워크 프로토콜 비활성화: Teredo, ISATAP, IPv6
- Windows 내장 진단 도구 및 디스크 조각 모음 비활성화

**블로트웨어 및 AI**
- OneDrive 및 Microsoft Edge 제거 (관련 데이터 및 WebView2 포함)
- Windows 10/11 기본 사전 설치 UWP 앱 제거
- AI 비서(Cortana, Copilot, Recall) 제거 및 비활성화

**인터페이스 및 알림**
- 테마, 창 설정, 작업 표시줄 레이아웃 및 아이콘 사용자 지정
- 개인 맞춤형 광고, 시스템 배너, SCOOBE, 알림 및 팁 비활성화

**하드웨어 및 성능**
- 키보드 및 마우스 설정 구성: 키 필터링, 고정 키, 포인터 가속 비활성화
- 최고 성능 전원 관리 옵션 적용
- 전원 설정을 통한 Realtek High Definition Audio 사운드 지연 문제 해결

**유지 관리 및 고급 설정**
- RAM, 임시 파일, 아이콘 캐시 정리
- 공간 절약을 위한 NTFS 파일 압축 및 압축 해제
- 하드웨어 구성 확인 및 시스템 구성 요소 모니터링
- TrustedInstaller 권한으로 사용자 지정 스크립트(`.ps1`, `.cmd`, `.bat`, `.reg`) 실행

## ✦ 시스템 요구 사항
```c++
Windows 지원: 10 이상 (빌드 18362.116)
설치된 플랫폼: .NET Framework 4.8
관리자 권한으로 실행: 필수
백신 프로그램: 제외 항목 추가 또는 비활성화
```

> ⚠️ 이 유틸리티는 신뢰할 수 있는 소스에서 다운로드한 공식 Windows 이미지 전용으로 설계되었습니다. Windows의 경량화/수정 버전을 설치한 경우, 해당 기능 작동에 대한 책임은 전적으로 사용자에게 있습니다.

<details>
<summary><b>GTweak 번역 방법</b></summary>
 
**I. Pull Request 제출**
- [여기](https://github.com/Greedeks/GTweak/fork)에서 리포지토리를 포크(Fork)합니다.
- [영어 기본 파일(Localize.xaml)](https://github.com/Greedeks/GTweak/blob/main/.Source/GTweak/Languages/en/Localize.xaml)을 다운로드하거나 다른 언어의 [기존 번역](https://github.com/Greedeks/GTweak/tree/main/.Source/GTweak/Languages)을 찾아 복사합니다.
- 파일을 번역하고 [언어 코드](https://learn.microsoft.com/en-us/windows-hardware/manufacture/desktop/available-language-packs-for-windows?view=windows-11)로 명명된 폴더에 저장합니다 (예: 한국어는 `ko`, 프랑스어는 `fr`).
</br>지역 변형의 경우: 언어-지역 (예: 브라질 포르투갈어는 `pt-br`, 간체 중국어는 `zh-cn`).
- 폴더 위치:
<div>
    <pre>
📂 .Source
└── 📁 GTweak
    └── 📁 Languages
        ├── 📁 en
        ├── 📁 ru
        └── 📁 [당신의-언어-코드]
    </pre>
</div>

- [LanguageCatalog](https://github.com/Greedeks/GTweak/blob/main/.Source/GTweak/Languages/LanguageCatalog.xaml)에 모국어로 작성된 언어 이름을 추가합니다.  
  ⚠️ 파일 내의 [NOTE](https://github.com/Greedeks/GTweak/blob/main/.Source/GTweak/Languages/LanguageCatalog.xaml#L5-L11)를 반드시 따르십시오.
- 변경 사항과 함께 **Pull Request**를 제출합니다. </br></br>

**II. Issue를 통한 요청**
- Git에 익숙하지 않은 경우 [Feature Request issue](https://github.com/Greedeks/GTweak/issues/new?template=%E2%9C%A8-feature-request-.yaml&title=[Feature]%20Add%20translation)를 엽니다.
  - 대상 [언어 코드](https://learn.microsoft.com/en-us/windows-hardware/manufacture/desktop/available-language-packs-for-windows?view=windows-11)를 지정합니다.
  - [NOTE](https://github.com/Greedeks/GTweak/blob/main/.Source/GTweak/Languages/LanguageCatalog.xaml#L5-L11)에 따라 모국어로 작성된 언어 이름을 제공합니다.
  - 번역된 `Localize.xaml` 파일을 첨부합니다.
</br>

</details>

> [!NOTE]  
> 현재 번역이 불완전할 수 있으며, 아직 번역되지 않은 새로운 기능이 추가되었을 수 있습니다. 이 경우 해당 프로그램 부분은 기본적으로 영어로 표시됩니다.
