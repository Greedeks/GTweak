## 주요 기능

GTweak은 Windows 운영 체제를 완벽하게 제어할 수 있는 포괄적인 도구 세트를 제공합니다. 여러 시스템 메뉴를 탐색할 필요 없이 단일 인터페이스에서 불필요한 백그라운드 서비스를 안전하게 비활성화하고, 내장된 블로트웨어를 제거하며, 고급 시스템 구성을 적용할 수 있습니다.

| 기능 | 세부 정보 |
|---|---|
| **시스템 정품 인증** | HWID 및 KMS 방식을 사용하여 Windows 정품 인증 |
| **보안 제어** | Windows Defender, SmartScreen, Antimalware, VBS 및 UAC 비활성화 |
| **업데이트 관리** | Windows 업데이트 비활성화 및 일시 중지; 임시 업데이트 파일 삭제 |
| **시스템 최적화** | 사용하지 않는 시스템 서비스, 불필요한 네트워크 프로토콜(Teredo, ISATAP, IPv6), 내장 진단 도구 및 디스크 조각 모음 비활성화 |
| **개인 정보 및 원격 분석** | Windows, NVIDIA 및 Intel의 키로거 및 원격 분석 비활성화. 데이터 수집 서비스, 작업 스케줄러 작업, 개인 맞춤형 광고, 시스템 배너, SCOOBE, 알림 및 팁 비활성화. 호스트 및 방화벽을 통해 데이터를 수집하는 Microsoft 섀도우 도메인 차단 |
| **디블로트 및 정리** | OneDrive 및 Microsoft Edge를 관련 데이터 및 WebView2와 함께 모두 제거. Windows 10/11에 기본 설치된 UWP 앱 및 AI 비서(Cortana, Copilot, Recall) 제거 |
| **UI 사용자 지정** | 테마, 창 설정, 작업 표시줄 레이아웃 및 아이콘 사용자 지정. 개인 맞춤형 광고, 배너 및 팁 비활성화 |
| **하드웨어 및 주변 장치** | 키보드 및 마우스 설정 구성: 키 필터링, 고정 키, 포인터 가속 비활성화. 최고 성능 전원 관리 옵션 적용. Realtek High Definition Audio 사운드 지연 문제 해결 |
| **디스크 및 유지 관리** | RAM, 임시 파일, 아이콘 캐시 정리 및 `Windows.old` 폴더 안전하게 삭제. NTFS를 사용하여 파일 압축 및 압축 해제를 통해 공간 절약 |
| **고급 제어** | 하드웨어 구성 보기 및 시스템 구성 요소 모니터링. TrustedInstaller 권한으로 사용자 지정 스크립트(`.ps1`, `.cmd`, `.bat`, `.reg`) 실행 |

<br/>

## 시스템 요구 사항

> ⚠️ 이 유틸리티는 신뢰할 수 있는 소스에서 다운로드한 공식 Windows 이미지 전용으로 설계되었습니다. Windows의 잘라낸/수정 버전을 설치한 경우 해당 기능에 대한 책임은 전적으로 사용자에게 있습니다.

```c++
Windows 지원: Windows 10 (build 18362.116)부터
설치된 플랫폼: .NET Framework 4.8
```

> [!WARNING]
> 응용 프로그램을 관리자 권한으로 실행하십시오.
> 
> 소프트웨어를 사용하기 전에 안티바이러스를 비활성화하거나 GTweak을 Windows Defender 제외 항목에 추가하십시오.

<details>
<summary><b>GTweak 번역 방법</b></summary>
 
**I. Pull Request 제출**
- 리포지토리를 [여기](https://github.com/Greedeks/GTweak/fork)에서 포크하세요.
- [영어 기본 파일 (Localize.xaml)](https://github.com/Greedeks/GTweak/blob/main/.Source/GTweak/Languages/en/Localize.xaml)을 다운로드하거나 다른 언어의 [기존 번역](https://github.com/Greedeks/GTweak/tree/main/.Source/GTweak/Languages)을 찾아 복사하세요.
- 파일을 번역하고 [언어 코드](https://learn.microsoft.com/en-us/windows-hardware/manufacture/desktop/available-language-packs-for-windows?view=windows-11) (예: 한국어는 `ko`, 프랑스어는 `fr`)로 명명된 폴더에 저장하세요.
</br>지역 변형의 경우: 언어-지역 (예: 브라질 포르투갈어는 `pt-br`, 중국어 간체는 `zh-cn`).
- 폴더를 다음 위치에 배치하세요:
<div>
    <pre>
📂 .Source
└── 📁 GTweak
    └── 📁 Languages
        ├── 📁 en
        ├── 📁 ru
        └── 📁 [당신의-언어-코드]
    </pre>
</div>

- 언어 이름(모국어로 표기)을 [LanguageCatalog](https://github.com/Greedeks/GTweak/blob/main/.Source/GTweak/Languages/LanguageCatalog.xaml)에 추가하세요.  
  ⚠️ 파일 내의 [참고](https://github.com/Greedeks/GTweak/blob/main/.Source/GTweak/Languages/LanguageCatalog.xaml#L5-L11)를 반드시 따르세요.
- 변경 사항이 포함된 **Pull Request**를 제출하세요. </br></br>

**II. Issue를 통한 요청**
- Git에 익숙하지 않다면 [기능 요청(Feature Request) Issue](https://github.com/Greedeks/GTweak/issues/new?template=%E2%9C%A8-feature-request-.yaml&title=[Feature]%20Add%20translation)를 여세요.
  - 대상 [언어 코드](https://learn.microsoft.com/en-us/windows-hardware/manufacture/desktop/available-language-packs-for-windows?view=windows-11)를 명시하세요.
  - [참고](https://github.com/Greedeks/GTweak/blob/main/.Source/GTweak/Languages/LanguageCatalog.xaml#L5-L11)에 따라 모국어로 표기된 언어 이름을 제공하세요.
  - 번역된 `Localize.xaml` 파일을 첨부하세요.
</br>

</details>
