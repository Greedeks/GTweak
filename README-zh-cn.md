## ✦ 随心调整

**激活与安全**
- 使用 HWID 和 KMS 方法激活 Windows
- 禁用 Windows Defender、SmartScreen、反恶意软件、VBS 和 UAC

**更新与服务**
- 禁用和暂停 Windows 更新；删除临时更新文件
- 禁用未使用和不必要的系统服务

**隐私与遥测**
- 禁用 Windows、NVIDIA 和 Intel 的键盘记录器和遥测功能
- 禁用与用户数据收集相关的服务、事件和任务计划程序任务
- 通过 hosts 文件和防火墙拦截微软影子域名

**网络与诊断**
- 禁用不必要的网络协议：Teredo、ISATAP 和 IPv6
- 禁用 Windows 内置的诊断工具和磁盘碎片整理

**臃肿软件与 AI**
- 卸载 OneDrive 和 Microsoft Edge 及其所有相关数据和 WebView2
- 移除 Windows 10/11 中标准的预装 UWP 应用
- 移除并禁用 AI 助手：Cortana、Copilot 和 Recall

**用户界面与通知**
- 自定义主题、窗口设置、任务栏布局和图标
- 禁用个性化广告、系统横幅、SCOOBE、通知和提示

**硬件与性能**
- 配置键盘和鼠标设置：按键过滤、粘滞键和指针加速
- 应用卓越性能电源计划
- 通过电源设置修复 Realtek 高清晰度音频的声音延迟问题

**维护与高级选项**
- 清理内存 (RAM)、临时文件和图标缓存
- 使用 NTFS 压缩和解压文件以节省空间
- 查看硬件配置并监控系统组件
- 使用 TrustedInstaller 权限执行自定义脚本（`.ps1`、`.cmd`、`.bat`、`.reg`）

<details>
<summary><b>如何翻译 GTweak</b></summary>
 
**I. 提交 Pull Request (拉取请求)**
- 在 [此处](https://github.com/Greedeks/GTweak/fork) Fork 此仓库。
- 下载 [英语基础文件 (Localize.xaml)](https://github.com/Greedeks/GTweak/blob/main/.Source/GTweak/Languages/en/Localize.xaml)，**或者**浏览并复制其他语言的 [现有翻译](https://github.com/Greedeks/GTweak/tree/main/.Source/GTweak/Languages)。
- 翻译该文件并将其保存在以您的 [语言代码](https://learn.microsoft.com/en-us/windows-hardware/manufacture/desktop/available-language-packs-for-windows?view=windows-11) 命名的文件夹中（例如，`ko` 代表韩语，`fr` 代表法语）。
</br>对于区域变体：语言-区域（例如，`pt-br` 代表巴西葡萄牙语，`zh-cn` 代表简体中文）。
- 将该文件夹放置在：
<div>
    <pre>
📂 .Source
└── 📁 GTweak
    └── 📁 Languages
        ├── 📁 en
        ├── 📁 ru
        └── 📁 [您的语言代码]
    </pre>
</div>

- 将您的语言名称（以您的母语书写）添加到 [LanguageCatalog](https://github.com/Greedeks/GTweak/blob/main/.Source/GTweak/Languages/LanguageCatalog.xaml)。  
  ⚠️ 请务必遵循文件内部的 [注意 (NOTE)](https://github.com/Greedeks/GTweak/blob/main/.Source/GTweak/Languages/LanguageCatalog.xaml#L5-L11)。
- 提交包含您更改的 **Pull Request**。</br></br>

**II. 通过 Issue 请求**
- 如果您不熟悉 Git，请开启一个 [Feature Request (功能请求) issue](https://github.com/Greedeks/GTweak/issues/new?template=%E2%9C%A8-feature-request-.yaml&title=[Feature]%20Add%20translation)。
  - 指定您的目标 [语言代码](https://learn.microsoft.com/en-us/windows-hardware/manufacture/desktop/available-language-packs-for-windows?view=windows-11)。
  - 根据 [注意 (NOTE)](https://github.com/Greedeks/GTweak/blob/main/.Source/GTweak/Languages/LanguageCatalog.xaml#L5-L11)，提供以您的母语书写的语言名称。
  - 附上您翻译好的 `Localize.xaml` 文件。
</br>

</details>

> [!NOTE]  
> 当前的翻译可能并不完整，因为可能添加了尚未翻译的新功能。在这些情况下，程序的这些部分将默认显示为英文。
