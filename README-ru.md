## Описание функций

GTweak предоставляет комплексный набор инструментов для полного контроля над операционной системой Windows. Вместо того чтобы перемещаться по множеству системных меню, вы можете безопасно отключать ненужные фоновые службы, удалять встроенный мусор и применять расширенные настройки системы из единого интерфейса.

| Категория | Описание |
|---|---|
| **Активация системы** | Активация Windows с использованием методов HWID и KMS |
| **Управление безопасностью** | Отключение Windows Defender, SmartScreen, Antimalware, VBS и контроля учетных записей (UAC) |
| **Управление обновлениями** | Отключение и приостановка обновлений Windows; удаление временных файлов обновлений |
| **Оптимизация системы** | Отключение неиспользуемых системных служб, ненужных сетевых протоколов (Teredo, ISATAP, IPv6), встроенных средств диагностики и дефрагментации дисков |
| **Конфиденциальность и телеметрия** | Отключение кейлоггеров и телеметрии для Windows, NVIDIA и Intel. Отключение служб сбора данных, задач в планировщике, персонализированной рекламы, системных баннеров (включая SCOOBE), уведомлений и советов. Блокировка «теневых» доменов Microsoft через hosts и брандмауэр |
| **Удаление мусора и очистка** | Удаление OneDrive и Microsoft Edge вместе с очисткой всех связанных данных и WebView2. Удаление стандартных предустановленных приложений (UWP) и ИИ-помощников: Cortana, Copilot и Recall |
| **Кастомизация интерфейса** | Настройка интерфейса: смена тем, параметров окон, расположения панели задач и иконок. Отключение персонализированной рекламы и баннеров |
| **Оборудование и периферия** | Настройка клавиатуры и мыши: отключение фильтрации ввода, залипания клавиш и акселерации курсора. Применение схемы питания «Максимальная производительность». Настройка электропитания драйверов Realtek High Definition Audio для устранения задержки звука |
| **Диск и обслуживание** | Очистка оперативной памяти, временных файлов, кэша и безопасное удаление папки `Windows.old`. Сжатие и восстановление файлов с помощью функций NTFS для экономии места |
| **Расширенное управление** | Просмотр конфигурации оборудования и мониторинг системных компонентов. Выполнение пользовательских скриптов (`.ps1`, `.cmd`, `.bat`, `.reg`) с правами TrustedInstaller |

<br/>

## Системные Требования

> ⚠️ Утилита предназначена только для официальных образов Windows, загруженных из надежных источников. Если у вас установлена обрезанная/измененная версия Windows, за работоспособность отвечаете вы сами.

```c++
Поддержка Windows: начиная с Windows 10 (build 18362.116)
Установленная платформа: .NET Framework 4.8
```

> [!WARNING]
> Запустите приложение от имени Администратора.
> 
> Перед использованием остановите антивирус или добавьте GTweak в исключения Windows Defender.

<details>
<summary><b>Как перевести GTweak</b></summary>
 
**I. Отправьте Pull Request**
- Сделайте форк репозитория [здесь](https://github.com/Greedeks/GTweak/fork).
- Скачайте [базовый английский файл (Localize.xaml)](https://github.com/Greedeks/GTweak/blob/main/.Source/GTweak/Languages/en/Localize.xaml) **или** скопируйте из [существующих переводов](https://github.com/Greedeks/GTweak/tree/main/.Source/GTweak/Languages) на другие языки.
- Переведите файл и сохраните его в папку с названием вашего [кода языка](https://learn.microsoft.com/en-us/windows-hardware/manufacture/desktop/available-language-packs-for-windows?view=windows-11) (например, `ko` для корейского, `fr` для французского).
</br>Для региональных вариантов: язык-регион (например, `pt-br` для бразильского португальского, `zh-cn` для упрощенного китайского).
- Поместите папку в:
<div>
    <pre>
📂 .Source
└── 📁 GTweak
    └── 📁 Languages
        ├── 📁 en
        ├── 📁 ru
        └── 📁 [ваш-код-языка]
    </pre>
</div>

- Добавьте название вашего языка (написанное на вашем родном языке) в [LanguageCatalog](https://github.com/Greedeks/GTweak/blob/main/.Source/GTweak/Languages/LanguageCatalog.xaml).  
  ⚠️ Обязательно следуйте [ПРИМЕЧАНИЮ](https://github.com/Greedeks/GTweak/blob/main/.Source/GTweak/Languages/LanguageCatalog.xaml#L5-L11) внутри файла.
- Отправьте **Pull Request** с вашими изменениями. </br></br>

**II. Запрос через Issue**
- Если вы не знакомы с Git, откройте [Feature Request issue](https://github.com/Greedeks/GTweak/issues/new?template=%E2%9C%A8-feature-request-.yaml&title=[Feature]%20Add%20translation).
  - Укажите ваш целевой [код языка](https://learn.microsoft.com/en-us/windows-hardware/manufacture/desktop/available-language-packs-for-windows?view=windows-11).
  - Укажите название вашего языка, написанное на вашем родном языке, в соответствии с [ПРИМЕЧАНИЕМ](https://github.com/Greedeks/GTweak/blob/main/.Source/GTweak/Languages/LanguageCatalog.xaml#L5-L11).
  - Прикрепите переведенный файл `Localize.xaml`.
</br>

</details>

> [!NOTE]  
> Текущий перевод может быть неполным, так как могли быть добавлены новые функции, которые еще не переведены. В таких случаях эти части программы по умолчанию будут отображаться на английском языке.
