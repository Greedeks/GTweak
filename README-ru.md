## ✦ Настройка всего и вся

**Активация и Безопасность**
- Активация Windows с использованием методов HWID и KMS
- Отключение Windows Defender, SmartScreen, Antimalware, VBS и контроля учетных записей (UAC)

**Обновления и Службы**
- Отключение и приостановка обновлений Windows; удаление временных файлов обновлений
- Отключение неиспользуемых и ненужных системных служб

**Конфиденциальность и Телеметрия**
- Отключение кейлоггеров и телеметрии для Windows, NVIDIA и Intel
- Отключение служб, событий и задач Планировщика, связанных со сбором данных пользователя
- Блокировка «теневых» доменов Microsoft через файл hosts и брандмауэр

**Сеть и Диагностика**
- Отключение ненужных сетевых протоколов: Teredo, ISATAP и IPv6
- Отключение встроенных средств диагностики Windows и дефрагментации дисков

**Bloatware и ИИ**
- Удаление OneDrive и Microsoft Edge вместе со всеми связанными данными и WebView2
- Удаление стандартных предустановленных приложений (UWP) в Windows 10/11
- Удаление и отключение ИИ-помощников: Cortana, Copilot и Recall

**Интерфейс и Уведомления**
- Настройка тем, параметров окон, расположения панели задач и иконок
- Отключение персонализированной рекламы, системных баннеров, SCOOBE, уведомлений и советов

**Оборудование и Производительность**
- Настройка клавиатуры и мыши: отключение фильтрации ввода, залипания клавиш и акселерации курсора
- Применение схемы питания «Максимальная производительность»
- Устранение задержки звука Realtek High Definition Audio через настройки электропитания

**Обслуживание и Дополнительно**
- Очистка оперативной памяти, временных файлов и кэша иконок
- Сжатие и распаковка файлов с помощью NTFS для экономии места
- Просмотр конфигурации оборудования и мониторинг системных компонентов
- Выполнение пользовательских скриптов (`.ps1`, `.cmd`, `.bat`, `.reg`) с правами TrustedInstaller
  
<br>

## ✦ Системные Требования
```c++
Поддержка Windows: начиная с 10 (build 18362.116)
Установленная платформа: .NET Framework 4.8
Запуск от имени администратора: обязательно
Антивирус: добавить в исключения или отключить
```

> ⚠️ Утилита предназначена исключительно для официальных образов Windows, загруженных из надежных источников. Если у вас установлена урезанная/модифицированная версия Windows, за ее работоспособность отвечаете только вы.

<details>
<summary><b>Как перевести GTweak</b></summary>
 
**I. Отправить Pull Request**
- Сделайте форк репозитория [здесь](https://github.com/Greedeks/GTweak/fork).
- Скачайте [базовый английский файл (Localize.xaml)](https://github.com/Greedeks/GTweak/blob/main/.Source/GTweak/Languages/en/Localize.xaml) **или** найдите и скопируйте из [существующих переводов](https://github.com/Greedeks/GTweak/tree/main/.Source/GTweak/Languages) на других языках.
- Переведите файл и сохраните его в папке с названием вашего [кода языка](https://learn.microsoft.com/en-us/windows-hardware/manufacture/desktop/available-language-packs-for-windows?view=windows-11) (например, `ko` для корейского, `fr` для французского).
</br>Для региональных вариантов: язык-регион (например, `pt-br` для бразильского португальского, `zh-cn` для упрощенного китайского).
- Поместите папку сюда:
<div>
    <pre>
📂 .Source
└── 📁 GTweak
    └── 📁 Languages
        ├── 📁 en
        ├── 📁 ru
        └── 📁 [ваш-код-языка]
    </pre>
</div>

- Добавьте название вашего языка (как оно пишется на вашем родном языке) в [LanguageCatalog](https://github.com/Greedeks/GTweak/blob/main/.Source/GTweak/Languages/LanguageCatalog.xaml).  
  ⚠️ Обязательно следуйте указаниям [NOTE](https://github.com/Greedeks/GTweak/blob/main/.Source/GTweak/Languages/LanguageCatalog.xaml#L5-L11) внутри файла.
- Отправьте **Pull Request** с вашими изменениями. </br></br>

**II. Запрос через Issue**
- Если вы не знакомы с Git, откройте [Issue Feature Request](https://github.com/Greedeks/GTweak/issues/new?template=%E2%9C%A8-feature-request-.yaml&title=[Feature]%20Add%20translation).
  - Укажите целевой [код языка](https://learn.microsoft.com/en-us/windows-hardware/manufacture/desktop/available-language-packs-for-windows?view=windows-11).
  - Укажите название вашего языка, написанное на родном языке, в соответствии с [NOTE](https://github.com/Greedeks/GTweak/blob/main/.Source/GTweak/Languages/LanguageCatalog.xaml#L5-L11).
  - Прикрепите переведенный файл `Localize.xaml`.
</br>

</details>

> [!NOTE]  
> Текущий перевод может быть неполным, так как могли быть добавлены новые функции, которые еще не переведены. В таких случаях эти части программы по умолчанию будут отображаться на английском языке.
